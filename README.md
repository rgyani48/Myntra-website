# 🛍️ Myntra Website Clone

A responsive front-end clone of the Myntra landing page built using **HTML5** and **CSS3**. This project recreates the look and feel of the official Myntra homepage with a modern, user-friendly, and mobile-responsive design.

## 🌐 Live Demo

https://rgyani48.github.io/Myntra-website/

## ✨ Features

- Responsive navigation bar
- Search bar with icons
- Hero banner section
- Shop by Category section
- Fixed offer sidebar
- Floating notification button
- Multi-column footer
- Mobile, tablet, and desktop responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries
- Google Material Symbols
- Git & GitHub
- GitHub Pages
